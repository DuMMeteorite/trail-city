# Тропа и Город (Trail & City)

Авторский веб-проект — каталог пешеходных маршрутов и интересных локаций для прогулок по городу и лесопарковым зонам.

## Реализованный функционал
- **Адаптивная семантическая вёрстка:** Flexbox, CSS Grid, CSS-переменные в `:root`, поддержка десктопа, планшетов (до 900px) и мобильных устройств (до 480px).
- **Интерактивный слайдер на JavaScript:** переключение стрелками, точками-индикаторами, автопрокрутка и пауза при наведении курсора.
- **Динамический каталог:** генерация 8 карточек маршрутов из JS-массива (`map` + `join`), фильтрация по категориям, поиск по названию и описанию, модальное окно «Подробнее».
- **Избранное (`localStorage`):** добавление и удаление маршрутов с синхронизацией между каталогом и личным кабинетом.
- **Авторизация и Личный кабинет:** регистрация с валидацией всех полей, вход по email и паролю, хранение сессии в `localStorage`, динамическое обновление шапки и защита страницы `cabinet.html` от неавторизованных пользователей.

## Структура проекта
- `index.html` — главная страница с Hero-блоком, слайдером, каталогом, блоком правил, FAQ и подвалом.
- `auth.html` — страница входа и регистрации.
- `cabinet.html` — защищённый личный кабинет пользователя с профилем и списком избранного.
- `css/style.css` — таблица стилей и адаптивные медиазапросы.
- `js/auth.js` — логика регистрации, входа, выхода, бургер-меню и защиты кабинета.
- `js/main.js` — массив маршрутов, рендер карточек, слайдер, модальное окно и фильтрация.
